# Saryarka Kitchen Website

## Project title and topic
**Saryarka Kitchen** - a multi-page website for a Kazakh and Central Asian restaurant in Astana.

## Group members
- Matiullah Zaman
- Member 2 Zainap Noori

## Short description
A responsive 5-page restaurant website with a menu table, gallery, and table reservation form. Theme: wine red, saffron gold and cream.

## Features implemented
- 5 pages (Home, About, Menu, Gallery, Reservations) linked by a sticky navigation bar on every page
- Semantic HTML5: `header`, `nav`, `main`, `section`, `article`, `aside`, `figure`, `footer`
- Table (menu with prices) and form (reservation form)
- External stylesheet `css/style.css`, no inline or internal styles
- Flexbox (header, footer, hours card, team cards) and CSS Grid (gallery, team, chef's picks)
- Positioning: `position: sticky` (header), `relative`/`absolute` (hours badge, check marks)
- `:hover`, `:focus`, `:focus-visible`; `:nth-child()` for alternating table rows, cards and captions
- CSS variables in `:root`; Google Fonts (Fraunces, Nunito Sans)
- `loading="lazy"` on below-the-fold gallery images
- Media queries at 992px (tablet) and 576px (mobile), desktop-first; header becomes vertical on mobile
- Bootstrap 5 grid and utilities

## Technologies used
HTML5, CSS3, Bootstrap 5.3 (CDN), Google Fonts, Git and GitHub Pages
